# עוזר להערכת מקרקעין

אב-טיפוס שולחני בעברית עבור שמאי/ות מקרקעין. בשלב זה סעיף `תיאור סביבת הנכס` מפעיל סוכן מציין מקום: הוא מציג את חמש המילים הראשונות בכל קובץ מצורף ושיר קצר על מקס ורסטאפן, כדי לבחון את זרימת העבודה בלי לשלוח מידע לשירות חיצוני.

## הרצה לפיתוח

דרושה התקנת Python 3.11 או חדש יותר. לאחר מכן, מתוך תיקיית הפרויקט ב-PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m appraisal_assistant
```

## שימוש

1. בחרו סעיף דוח. רק `תיאור סביבת הנכס` פעיל בשלב זה.
2. מלאו כתובת ודוגמה. הבקשה הנוספת היא אופציונלית.
3. לחצו `צור`.
4. ערכו את התוצאה כרצונכם.

יש שתי תיבות תוכן: `דוגמה` ו-`בקשה נוספת`. בכל תיבה אפשר לכתוב או להדביק טקסט חופשי, לגרור קבצים ישירות לתיבה, או ללחוץ על סמל פתיחת הקובץ באזור `קבצים מצורפים`. הקבצים מוצגים כאייקונים קצרים ברוחב קבוע עם `×` להסרה; סרגל גלילה אופקי מאפשר לעבור על כל הקבצים. שם הקובץ מופיע בהעברת העכבר מעל האייקון. לדוגמה חובה למסור לפחות טקסט או קובץ אחד. הפורמטים הנתמכים הם: PDF, Word (`.doc`, `.docx`), Excel (`.xls`, `.xlsx`), CSV, TXT ו-Markdown.

בגרסת הפיתוח סוכן הדמה קורא כל קובץ מקומי ומציג את חמש המילים הראשונות ממנו, כדי לאמת שהקובץ הועבר אליו. סוכן אמיתי עתידי ישתמש באותן רשומות כדי להעביר את הקבצים שנבחרו במפורש לספק ה-AI המתאים.

## פרטיות

כברירת מחדל, גרסת הפיתוח אינה שולחת נתונים לרשת. בוחרים במסך בין `ChatGPT (OpenAI)` ובין `Gemini`; לחיצה על `צור` שולחת את הקלטים והקבצים רק לספק שנבחר.

## הפעלת סוכן Gemini

כאשר מוגדרים שני משתני סביבה, האפליקציה מפעילה את `GeminiEnvironmentDescriptionAgent` במקום הסוכן המקומי:

```powershell
$env:GEMINI_API_KEY = "מפתח-ה-API-שלך"
$env:GEMINI_MODEL = "מזהה-המודל-בפרויקט-שלך"
python -m pip install -e ".[dev]"
python -m appraisal_assistant
```

המפתח אינו נשמר בפרויקט. בעת לחיצה על `צור`, הכתובת, טקסטי הקלט והקבצים שנבחרו נשלחים לספק הנבחר. הגדרת ההתנהגות המקצועית של סוכן תיאור הסביבה נמצאת ב-`src/appraisal_assistant/agents/prompts/environment_description.md`; אפשר לעדכן אותה בלי לשנות את ממשק המשתמש, הטיפול בקבצים או תשתית ה-API.

## בחירת ספק AI

ברשימת `סוכן AI` אפשר לבחור בין `ChatGPT (OpenAI)`, `Gemini`, `Claude (Anthropic)`, `Kimi (Moonshot)` ו-`Qwen (DashScope)`. לחצו על סמל גלגל השיניים בראש החלון כדי להדביק את מפתח ה-API ולבחור מזהה מודל. בראש מסך ההגדרות נמצא ספק ברירת המחדל, ומופרד בקו ברור מהגדרות הספק (מפתח ומודל) שמתחתיו. המפתח נשמר במאגר האישורים של Windows, ולא בפרויקט או בקובץ ה-EXE; בהגדרות הוא נשאר מוצג בשדה מוסתר כדי שאפשר יהיה לראות שנשמר. אפשר גם לקבוע ספק ברירת מחדל, שייבחר אוטומטית בפתיחת האפליקציה. הרשימה מציעה מודלים לכל ספק, ואפשר גם להקליד מזהה מודל אחר שהחשבון שלכם מאפשר. בעת הבדיקה, התוצאה מתחילה במזהה המודל שנבחר.

אפשר עדיין להשתמש במשתני סביבה: `OPENAI_API_KEY` / `OPENAI_MODEL`, `GEMINI_API_KEY` / `GEMINI_MODEL`, `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL`, `MOONSHOT_API_KEY` / `MOONSHOT_MODEL`, או `DASHSCOPE_API_KEY` / `DASHSCOPE_MODEL`. הגדרה שנשמרה במסך ההגדרות מקבלת עדיפות על משתנה סביבה.
